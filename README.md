# Reiseatelier

Reiseplanungs-App für die AIDAdiva-Weltreise 2027/28: Route mit Karte, Reiseplanung, Reisetagebuch mit Fotos und Countdown. Läuft komplett im Browser, offline-fähig und als App auf dem Home-Bildschirm installierbar.

**Zur App:** https://mrfloyd84.github.io/reiseatelier/

Alle Reisedaten bleiben auf den Geräten der Nutzerinnen und werden über eine Abgleich-Datei in einem geteilten iCloud-Drive-Ordner synchronisiert. Im Repository liegt nur die leere App. Details zu Installation und Abgleich: [ANLEITUNG.md](ANLEITUNG.md).
